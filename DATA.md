# Runtime data

Committed JSON catalogs contain game-derived identifiers, row indices, original values, model names and display labels required for building and running the selectors. Costume metadata retains only the table ID, row count, row keys and names used by the application. A binary game database is not required to build this source distribution.

The standalone plan contains 41 curated plan targets plus six named catalog targets. The four Amon target records are identical to the records in the included CT v1.3.0-rc1 plan; the standalone engine applies them through its ten-slot source layout. The CT keeps its own dual-source plan and catalogs so its original artifact can be reproduced unchanged.

The committed data is the build input; this distribution does not include the complete game extraction toolchain. The NPC catalogs represent selectable candidates, not a claim that every model has been validated in gameplay.
