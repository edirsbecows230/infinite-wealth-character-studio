# v0.7.0

- Public standalone release with the ten-slot interface and named character selection.
- Added Jo Amon, Jiro Amon, Kazuya Amon and Sango Amon using the CT v1.3.0-rc1 records.
- Retained six additional named targets, restore controls and voice override support.
- Included self-contained build inputs, minimal costume metadata and offline transaction tests.

The four Amon targets were reported tested in the CT by the maintainer. This does not substitute for in-game testing of the newly built standalone executable.
